# Field Notes

## The problem

Independent neighborhood places are scattered across paid listings and social posts.

## How this project helps

So I built a searchable, community-maintained guide with clear details and a submission path.

### Learning goals

- Validate place submissions.
- Implement search and category filters.
- Persist saved places and prevent duplicates.

### I am done when you can

- Submit a new place.
- Search and filter categories
- Save a place and it persists
- Show loading, empty and more error states
- change the website via the viewport

## Run the project

From the root, install once with `npm install`, then run `npm run dev --workspace=field-notes`. You can also run `npm run dev` from this folder. Build with `npm run build --workspace=field-notes`.

## Contributing
